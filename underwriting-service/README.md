# Loan Underwriting Service

This non-web Spring Boot service consumes safe loan application events, evaluates the demo underwriting policy, stores idempotent decisions, and publishes decision events back to the API service.

For the package map and recommended reading order, see [`../docs/PROJECT_STRUCTURE.md`](../docs/PROJECT_STRUCTURE.md). For setup and run commands, see the repository [`README.md`](../README.md).
